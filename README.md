# Blackboard Log Converter Tool

This project provides a command-line tool for converting Blackboard Learn log files into structured formats for easier analysis and processing.

## 🔧 Features

- Converts raw log files into structured formats.
- Supports multiple output formats:
  - `flat`: Flattened key-value structure.
  - `json-legacy`: JSON format compatible with legacy systems.
  - `json-distributed`: JSON format with distributed nested structure.
- Includes host filtering and search capabilities.
- Logging support for debugging and audit trails.
